# NeuroFairy

A local-first ADHD companion: MCP tools, a focus timer, and a desktop fairy.

Status: **Stage 1 — in progress.**

## What this is

Fairy exposes your real life — tasks, focus time, calendar, notes — to an AI assistant
as [MCP](https://modelcontextprotocol.io) tools, then grows its own agent and interface
around them. Everything runs on your machine. Nothing is uploaded anywhere.

## Setup

```bash
uv sync
uv run pytest
```
